الدخول إلى لوحة التحكم

أدخل GitHub Token الخاص بك للوصول. التوكن يُحفظ على جهازك فقط — لن يُرسل لأي جهة خارجية.

كيف تحصل على Token؟

  1. افتح github.com/settings/tokens/new
  2. اختر اسماً (مثل: KON Admin)
  3. فعّل صلاحية: repo → contents (read & write)
  4. اضغط "Generate token" وانسخ الكود
  5. الصقه هنا واضغط دخول
